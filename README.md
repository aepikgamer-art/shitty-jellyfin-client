# shitty-jellyfin-client

A deliberately janky, zero-polish Jellyfin media player client for Windows.

## Why

Because the official clients are too good and I needed something worse.

## Features

- [x] No .NET SDK, no browser, no web app, no install
- [x] Runs on stock Windows: PowerShell + WPF is all it uses
- [x] Native window with a native MediaElement player (video plays INSIDE the app)
- [x] Seek bar (a polling-timer hack, but it works)
- [x] Play/pause button
- [ ] Aesthetics
- [ ] Subtitles, audio track selection, or respect

## Run

Double-click `run.bat`. That's it. That's the whole install.

## Disclaimer

This is a joke-tier client. Use the real ones if you want happiness.
